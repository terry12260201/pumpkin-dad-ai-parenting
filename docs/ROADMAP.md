## 🔴 高優先：講座前必做

### 1. Rotate API Key 並從程式碼移除
**為什麼：** 目前 Gemini API Key 寫死在 `vocab/index.html` 和 `recipe/index.html` 的 `DEFAULT_KEY`。如果這個 repo 推到公開平台，Key 會被爬蟲偷走。

**怎麼做：**
1. 到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 撤銷舊 Key
2. 申請新 Key
3. 三選一：
   - **方案 A（推薦）：** 把 `DEFAULT_KEY = '...'` 改成 `DEFAULT_KEY = ''`，講座當天透過工具右上角「設定 API Key」貼新 Key（存 localStorage）
   - **方案 B：** 把 Key 放 `.env`，用 build script 在發布前注入（需要 build flow，比較複雜）
   - **方案 C：** Repo 私有 + Key 寫死。如果你不會分享 repo，這個最簡單

**檔案：**
- `vocab/index.html` 第 ~410 行
- `recipe/index.html` 同樣 DEFAULT_KEY 常數
