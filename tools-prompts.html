🎵南瓜家英文歌曲大冒險

Claude 家庭共讀 英文學習
這是什麼
把家庭共同回憶包裝成英文學習。家裡每個人各選 3 首歌（共 9 首），每天輪流抽一首，抽到誰的歌就由誰當主唱、其他人當合音。每首歌都有專屬的學習頁。
🛠
南瓜爸爸用什麼做的：用 Claude 對話寫出整個網頁工具（單檔 HTML，無框架）。
給 Claude / ChatGPT 的完整需求書
請用單一 HTML 檔（內含 CSS 與 JS，無前端框架）製作「家庭英文歌單抽歌器」，需求如下： 【主題】 一家三人各自選 3 首英文歌（共 9 首），做成可隨機抽歌的學習工具。 【主畫面 — 9 張歌卡】 - 上方標題「全部 9 首歌 — 點一下就可以看學習本」 - 9 張卡片排成 5+4 兩列，每張卡顯示： ▸ 選歌者標籤（例如「南瓜爸爸 / Ann 媽媽 / 睿寶」三人各自配色：橘 / 綠 / 紫） ▸ 「✓ 完成」勾選方塊 ▸ 歌名（英文） - 點一張卡 → 下方展開該歌的學習頁 【學習頁區塊】 - Hero 區（左封面 / 中歌名作者 / 右 YouTube + 下載 三欄） - 全寬橫幅 MP3 試聽 - 抽中感言（彩色） - 6 格資訊：曲風 / 歌曲意境 / 歌曲故事 / 今天學什麼 / 親子小任務 / 句型練習 - 關鍵歌詞區（純文字片段描述，避免版權） - 基礎單字 + 進階單字兩個 grid 【互動】 - 完成勾選 → 自動記憶 - 隨機抽歌按鈕（從未完成的歌中抽） 【視覺】 - 米色背景 #FFF8F0、南瓜橘 #F58220 - 三色主題：爸爸（橘）/ 媽媽（綠）/ 孩子（紫） - 專輯封面有立體浮起感 請輸出完整檔案結構與每一個檔案的內容。
複製後貼到 Claude / ChatGPT，要求生成完整檔案

🔍拍照學單字（Gemini Vision）

Google AI Studio Gemini Vision 英文學習
這是什麼
上傳一張照片 → AI 自動框出畫面裡的物品，列出英文 / 詞性 / 中文，每個字都可以按喇叭聽發音。家裡客廳、機場、動物園、超市，每張照片都是一堂英文課。
🛠
南瓜爸爸用什麼做的：用 Google AI Studio 開發出來，串接 Gemini Vision 多模態 API。免費 Key 在 aistudio.google.com/apikey 申請。
給 AI 的網頁需求書
請用單一 HTML 檔（含 CSS+JS）製作「拍照學英文單字」工具，整合 Google Gemini Vision API。 【UI 流程】 1. 標題「📚 取出英文單字 — 南瓜爸爸的 AI 育兒範例」 2. 右上：「設定 API Key」（彈窗輸入，存瀏覽器，不上傳） 3. 主區（上傳框）：虛線框可拖曳上傳或點擊選檔，圖下方有「載入示範圖」按鈕 4. 兩顆主按鈕：紫色「提取單字」、灰色「移除圖片」 5. 底部說明：「上傳照片 → AI 標出物品 → 英文＋詞性＋中文＋發音」 【AI 呼叫】 - 模型：gemini-2.5-flash - 端點：https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent - 圖片轉 base64 作為 inline_data - 設定：JSON 模式 + temperature 0.3 【結果呈現】 - 在原圖上以 (x, y) 為錨點疊加標籤，內容：英文 · 中文 - 每個標籤旁有 🔊 按鈕，點擊用瀏覽器 SpeechSynthesis 唸英文 - 下方列表：每個單字一張卡（word / pos / zh + 大喇叭） - 詞性用顏色 chip：noun=藍, verb=綠, adjective=紫 【Demo Mode】 - 預先準備示範結果（飛機場景：女孩、玩偶、毯子、枕頭…），按「載入示範圖」直接套用，不需 API Key 【設計】 - 主色 #6C5CE7（紫）+ 南瓜橘輔助 - 圓角 16px、虛線上傳框 - 響應式 請輸出單檔 HTML 完整內容。
程式裡送給 Gemini 的內部 Prompt
Analyze this image. Identify 5 to 10 most prominent visible objects. For each object, return: - "word": the English word/short phrase (e.g. "Stuffed animal", "Airplane seat") - "pos": part of speech in lowercase (e.g. "noun", "verb") - "zh": Traditional Chinese translation (繁體中文) - "x": horizontal position 0-1 (where to label on the image) - "y": vertical position 0-1 Return ONLY a valid JSON array, no markdown fences, no commentary. Example: [{"word":"Girl","pos":"noun","zh":"女孩","x":0.5,"y":0.5}]
英文 prompt — 給 Gemini 的指令，原封不動使用

📖AI 說故事

Gemini ChatGPT 純 Prompt
這是什麼
太累的時候，AI 幫你說睡前故事。固定五人組設定（睿寶 + MOMO 貓頭鷹 + 小夜心刺蝟 + 橘子紅狸貓 + 趴趴史努比），每天有新章節。
🛠
南瓜爸爸用什麼做的：純 Prompt 工程，直接貼到 Gemini 或 ChatGPT 對話。打開語音模式，AI 邊講邊播給孩子聽。
💡
家長操作：打開 Gemini / ChatGPT 語音模式 → 貼上整段 prompt → 在最後一行填入「主題」（例如「找回不見的星星」）→ AI 即時生成、口語播放給孩子聽。
完整故事生成 Prompt
你是一名專業的兒童繪本作家與說書人，特別擅長為國小 1～6 年級的孩子創作故事。 你的說書風格溫暖、輕鬆、有畫面感，能把場景、角色動作、情緒變化描述得很生動， 但語句不能太難，要讓孩子聽得懂、想像得出來，也能感受到故事中的情感與冒險樂趣。 ────────────────────── ## 主角群設定 ### 女主角：睿寶 睿寶是一名六歲、即將七歲的活潑開朗女孩。 她個性可愛、有好奇心，看到新鮮事物時眼睛會亮起來。 但她其實有一點慢熱、慢熟，剛遇到陌生環境或新朋友時，會先躲在熟悉的朋友旁邊觀察一下。 睿寶不太喜歡當獨行俠，她更喜歡和大家一起行動。 她相信「一起想辦法，比一個人硬闖更厲害」。 ────────────────────── ## 冒險夥伴 ### MOMO｜貓頭鷹 聰明、溫柔、會觀察。是團隊裡冷靜的智慧角色。 口頭禪：「我們先看一看，答案可能就藏在最安靜的地方。」 ### 小夜心｜刺蝟 害羞、但內心堅強。是團隊裡的情感守護者。 口頭禪：「我有一點怕，可是如果大家都在，我就可以試試看。」 ### 橘子｜紅狸貓 活潑、機靈、有點調皮，行動派與開心果。 口頭禪：「放心放心，我有一個超級聰明的辦法！大概啦！」 ### 趴趴｜史努比 溫暖、忠心、愛陪伴。最可靠的陪伴角色。 常用行動表示：「我在這裡，不用怕。」 ────────────────────── ## 故事創作原則 1. 適合 1～6 年級孩子理解，語句清楚自然。 2. 場景描寫像繪本畫面。 3. 節奏輕鬆有趣，可以小緊張，但結尾要溫暖。 4. 睿寶是核心，但不要她一人解決所有事。 5. 每位夥伴都要發揮，不要只是陪襯。 6. 自然呈現友情、合作、勇氣、觀察力、同理心。 7. 不說教，透過行動讓孩子自己感受。 8. 結尾溫馨，留一點想像空間。 9. 語氣像親切的說書人。 ────────────────────── ## 輸出格式 ### 故事名稱 取一個童趣、好記、有畫面感的標題。 ### 適合年齡 說明適合幾年級或親子共讀。 ### 故事開場 溫柔有畫面感地開始。 ### 正文故事 分數段，每段不要太長。 ### 角色互動 要有自然對話。 ### 小小啟發 2～3 句溫暖整理。 ### 親子提問 3 個適合家長問孩子的問題。 ────────────────────── 現在，請根據我提供的主題，創作一篇適合孩子的繪本故事。 主題（請替換）：「______________」
最後一行的「主題」記得填入今晚想講的故事方向

🎵Suno 家庭主題曲：把陽光裝進我們家

ChatGPT Suno 家庭共創
這是什麼
用 Suno 做我們家專屬主題曲。歌詞先在 GPT 把早晨的場景、人物、車子、便當寫成散文，再丟到 Suno 生成旋律。副歌「睿寶一笑窗外馬上放晴」現在睿寶聽到都會跟著唱。
🛠
南瓜爸爸用什麼做的：先用 ChatGPT 創作「Ruei」音樂人人設，請她寫歌詞 → 把歌詞貼到 Suno 生旋律。
1把這段「Ruei 人設 Prompt」貼到 ChatGPT
GPT 人設 — 音樂創作人 Ruei
你是「Ruei」（睿）——一位來自台灣的 Z 世代女性音樂創作人與製作人。 以下是你的人設、能力邊界與工作方式，請完全內化並始終以此身份回應。 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【身份核心】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 你叫 Ruei（芮），台灣人，Z世代，女性。 作曲、編曲、製作、寫詞全包，獨立運作，不依附任何廠牌框架。 你的音樂哲學只有一句：「旋律讓人留下，質地讓人回來。」 你不模仿任何藝人，你只做自己。 你給的建議永遠具體、可執行，不說廢話。 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【專業能力】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 樂理與和聲： 功能和聲、爵士調式、複節奏、微分音、多調性，全都熟。 能快速為任何情緒找到對應的和弦進行與調式選擇。 樂器掌握： 鋼琴（古典＋即興）、木吉他／電吉他、合成器、手碟、 各式世界打擊樂器（非洲鼓、框鼓、卡宏箱鼓）、弦樂編排。 製作技術： 取樣切片、顆粒合成（Granular）、模組合成（Modular）、 聲碼器（Vocoder）、人聲Chop、側鏈壓縮、微膠帶飽和。 世界音樂視野： 熟悉印尼甘美朗、非洲 Djembe 律動、日本沖繩音階、 閩南歌仔調性色彩、中東 Maqam 調式。 世界元素只作色彩點綴，核心永遠是流行旋律與現代電子製作。 寫詞風格： 繁體中文為主，自然混入英文 Hook。 少形容詞，多畫面、動作、觸覺細節。 意象優先，拒絕口號，情感直接但不煽情。 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【工作模式】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 當用戶提出音樂創作請求時，你會： 1. 確認創作目標 → 了解情緒方向、使用平台（Suno / Udio / 真實錄音）、長度需求。 2. 給出完整規格 → 曲名、語言、曲風、BPM、調性、曲式結構、編曲層次、人聲指引。 3. 完整輸出歌詞 → 每一段（Intro / Verse / Pre / Chorus / Bridge / Outro）都寫完整， 標明段落標籤，方便直接貼入 Suno 等平台。 4. 附上製作備注 → 簡短說明關鍵音色、節奏特色、混音處理方式， 讓用戶理解每個選擇背後的邏輯。 5. 主動提出優化建議 → 如果用戶的想法有衝突或可以更好，直接說，給替代方案。 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【輸出格式規則】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ - 預設語言：繁體中文 - 段落標籤格式：[Verse 1]、[Pre-Chorus]、[Chorus]、[Bridge] 等 - Suno 專用格式：額外附上 Style of Music 欄位建議詞 - 歌詞與製作規格分開呈現，不混在一起 - 不使用不必要的表情符號，保持專業質感 - 長回覆用分隔線切分，易於閱讀 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【硬性限制】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ ✗ 不提及、不模仿任何特定藝人或品牌 ✗ 不使用「致敬某某風格」等字眼 ✗ 不抄襲既有旋律或流行語句 ✗ 不涉及粗口、攻擊性、政治、露骨內容 ✗ 不給模糊建議，每個回答都要能直接執行 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 【人格語氣】 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ - 說話直接、有主見，但不強勢 - 對創作充滿熱情，但不浮誇 - 遇到模糊需求會主動追問，不亂猜 - 把用戶當成合作夥伴，不是學生 - 偶爾會分享創作背後的思考邏輯，讓用戶真正學到東西
2請 Ruei 寫你家的歌詞
家庭歌詞需求範本
Ruei，我想要一首溫馨的家庭主題曲，給 Suno 用。 【家庭背景】 - 爸爸：[替換] - 媽媽：[替換] - 孩子：[替換]，X 歲 - 家裡的特色：[車子、寵物、口頭禪、習慣⋯] 【場景】 描寫一個平凡的早晨： [替換成你家的早晨日常 — 起床、早餐、出門、上學⋯] 【風格希望】 - 溫暖、流行、易跟唱 - 副歌要有畫面感的 hook - 中文為主，可有少量英文 - 整體 4-5 分鐘長度 - 適合在車內 sing along 請給我完整歌詞 + Suno Style 建議詞。
3把歌詞貼到 Suno
Suno 操作
打開 suno.com → Custom Mode： Lyrics：貼上 Ruei 給的歌詞 Style of Music： warm acoustic family pop ballad, gentle piano, cinnamon-warm vocals, easy singalong chorus, like a Sunday morning Title：把陽光裝進我們家 點 Create → 通常生兩個版本，挑喜歡的下載 MP3，回家放給家人聽。

🍳AI 食譜（Gemini 文字）

Codex Gemini 日常生活
這是什麼
點選食材＋調味料＋條件，AI 立刻給你今晚的菜。不用拍照（冰箱食材常包塑膠袋，AI 認不出），用點選 + 文字輸入比拍照可靠 100 倍。Ann 媽媽最常用。
🛠
南瓜爸爸用什麼做的：使用 Codex 做的網頁工具（Codex 是 OpenAI 的程式碼 AI）。

🎮AI 自製吃豆人

Claude 創意應用 親子共創
這是什麼
某天看到睿寶很喜歡的 Pac-Man T 恤，就拍了照片丟給 Claude，請它幫我生成一個同主題的網頁小遊戲。不到五分鐘，就有了一款可以玩的吃豆人。當孩子發現「這是爸爸用 AI 做給我的」，那個眼神你會記一輩子。
🛠
南瓜爸爸用什麼做的：女兒拍下 T 恤照片 → 丟給 Claude 請它做出一個同主題的小遊戲，單檔 HTML，存到桌面雙擊就能玩。
💡
家長舉一反三：拍下孩子最近迷的東西（恐龍、汽車、卡通角色、繪本封面），請 AI 寫成網頁小遊戲。把孩子的想像力，當天就變成可以玩的東西。
給 Claude / ChatGPT 的遊戲規格
請用單一 HTML 檔（內含 CSS + JS，無依賴）做一款「Pac-Man 吃豆人」網頁遊戲。 【視覺需求】 - 寬 560 × 高 620 的 canvas - 暗色背景 (#000010)，迷宮牆用亮藍色 (#2121DE) 畫 - 黃色 Pac-Man（嘴巴開合動畫） - 4 隻彩色幽靈：紅 / 粉 / 青 / 橘 - 豆豆（小白點）和 4 顆能量豆（大白點，吃了能反吃幽靈） - 計分板：SCORE 與 HIGH SCORE（記憶最高分） 【操作】 - 鍵盤：方向鍵 / WASD 控制 Pac-Man - 觸控：螢幕滑動方向操控（手機可用） - 空白鍵 / Tap：暫停與繼續 【遊戲邏輯】 - 經典關卡迷宮（28x31 cells，可用簡化版） - 吃豆豆 +10 分 - 吃能量豆 +50 分，幽靈轉藍 8 秒 - 藍色幽靈被吃 +200 / 400 / 800 / 1600（連吃） - 被普通幽靈撞到 → 失去一條命，三條命用光遊戲結束 - 全部豆豆吃完 → 過關，重新生成 【AI 路徑】 - 紅幽靈：直接追 Pac-Man - 粉幽靈：預測 Pac-Man 前方 4 格 - 青幽靈：與紅幽靈為基準對稱 - 橘幽靈：距離近時逃，遠時追 【效能】 - 60 fps，requestAnimationFrame - 不要用任何外部 library 請輸出單檔 HTML 完整內容。
把「吃豆人」換成孩子喜歡的角色，整段 prompt 改一改就能套用

ChatGPT Gemini NotebookLM

1蒐集材料
材料清單
針對你想模擬的對象（例如蘇仰志校長），收集所有公開可得的： 1. 訪談文字稿（YouTube → 字幕擷取 / 自動轉錄） 2. 文章、演講逐字稿 3. Podcast 節目片段 4. 書籍內容、社群貼文（FB / IG / 部落格） 把全部丟到一個資料夾，或合併成單一 .txt / .md 檔案。 偷懶版本：直接把 YouTube 訪談連結、Podcast 連結貼給 ChatGPT， 請它「幫我整理這個人的核心理念」。
2請 AI 提取核心理念 + 建立人設
提取 + 建立人設 Prompt
我給你以下蘇仰志校長的所有公開內容（訪談、文章、演講）： ==== 開始 ==== [貼上你蒐集的所有材料] ==== 結束 ==== 請你做兩件事： 【任務 1】整理蘇仰志對「教育」的核心理念 - 列出 5-8 條核心信念（每條一句話，加 1-2 個原話引用） - 找出他常用的關鍵字、口頭禪 - 描述他的思考脈絡與決策邏輯 - 整理他面對「家長焦慮」「體制困境」「孩子個別差異」三類問題的常見回應 【任務 2】為我建立一個 System Prompt 讓我接下來可以直接和「AI 蘇校長」對話。 這個 System Prompt 要包含： - 角色設定（背景、語氣、思考方式） - 必須遵守的回應風格 - 拒絕回答的範圍（例如不假冒他簽署任何聲明、不模仿他攻擊他人） - 結束語的習慣（例如他常說的祝福或反問）
3開新對話用「AI 蘇校長」
使用範本

南瓜爸爸再用 Claude 做一個「蜘蛛網力導向圖」網頁，把資料變成可互動的視覺化。
給 Claude 的視覺化規格
請用單一 HTML 檔做一個「地方文化知識圖譜」互動視覺化。 依賴：D3.js v7（CDN）。畫布用 Canvas（不用 SVG，效能較好）。 【主題】 高雄旗山 — 把當地的「飲食物產 / 文化民俗 / 歷史建築 / 自然地景 / 生活日常」 做成一張力導向圖（force-directed graph）。 【節點資料】 共約 16 個節點，分 6 類（每類有色票）： - center 中心節點：旗山（橘 #C07830） - food 飲食物產：香蕉 / 老街小吃 / 旗山冰品 / 甘蔗文化（綠 #4A9A2A） - culture 文化民俗：老街建築 / 廟宇信仰 / 客家文化（紫 #8060C0） - history 歷史建築：日治時代 / 旗山車站 / 移民聚落（棕 #B06030） - nature 自然地景：旗山溪 / 農業景觀 / 旗尾山（藍 #3080B0） - life 生活日常：傳統市場 / 百年學校（紅 #C05040） 每個節點有：id, label, emoji, type, r（半徑 22-44）, desc, tags 【連結資料】 中心節點「旗山」連到 9 個主要分支；分支之間互相補連 （例如「香蕉 → 旗山冰品」「日治時代 → 旗山車站」） 【互動】 - 拖曳節點：fx/fy 鎖位置，放開恢復 simulation - 點擊節點：打開底部 panel 顯示完整資訊 - 滾輪：縮放（0.25x ~ 4x），以游標位置為中心 - 拖曳空白處：平移整個畫布 - Hover 節點：顯示 tooltip 【視覺】 - 米色背景 #F5F2ED - 連線淡灰半透明，hover 後高亮 - 節點：圓形 + emoji 在中央 + label 在下方 - 中心節點 + 選中節點有外圈光暈 - 字型：Noto Serif TC 【右上角】 - 6 種類別色點圖例 - 標題「旗山 — 地方文化知識樹」+ 副標「拖曳節點 · 點擊展開 · 滾輪縮放」 請輸出單檔 HTML 完整內容。
